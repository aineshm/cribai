     - Create user message immutably and append to messages
     - Set loading = true
     - POST to `/api/ai/cribai` with body `{ query: text.trim(), campusSlug: 'uw-madison', history: [] }`

     - Use TextDecoder to decode chunks, maintain a buffer string across reads
     - Split buffer on `\n\n` (SSE event boundary), keep incomplete last part in buffer
     - Parse each `data: ` line as JSON: `{ type: string, content?: string, message?: string }`

     - On `type === 'error'`: set assistant message content to error message
     - Wrap in try/catch: on error, append error message as assistant message
     - Finally: set loading = false
