## Goal

Enhance the listing detail page with photo gallery, map, freshness indicators, CribAI CTA, and similar listings. Create the saved listings page and add "Saved" nav links.

## Tasks

### Task 1: Enhanced listing detail page

**Files:** `apps/web/app/(campus)/[campusSlug]/listings/[id]/page.tsx`

Rewrite the existing detail page (129 lines) to add:

1. **Photo gallery at top**: Import `ListingPhotoGallery` from `apps/web/components/listing-photo-gallery.tsx`. Pass `photoUrls={listing.photo_urls ?? []}`, `sourceUrl={listing.source_url}`, `address={listing.address}`. Place above the title. Satisfies LIST-03.

2. **HeartButton**: Add HeartButton (from 04-01) next to the title/price area (size="md"). Fetch saved state from `saved_listings` for current user.

3. **FreshnessBadge**: Import from `apps/web/components/freshness-badge.tsx`. Render in key info section using `listing.last_seen_at`. Also display `listing.first_seen_at` as "Posted X days ago" if available. Satisfies LIST-04.

4. **Mapbox map**: Create a simple single-listing map using react-map-gl (already installed), centered on listing coordinates with a single marker. Only render if listing has latitude/longitude. Use `NEXT_PUBLIC_MAPBOX_TOKEN` env var. If ChatMapBlock props don't support standalone use, create a simpler `ListingLocationMap` inline or as a small component.

5. **"Ask CribAI about this place" CTA**: Link to `/${campusSlug}/cribai?listingId=${listing.id}`. Style as secondary button with chat icon.

6. **"Similar nearby" section**: Query 3 listings with price +-30%, same campus_id, excluding current, ordered by price proximity. Render with ListingCard in responsive grid. Pass saved state.

7. **Layout**: Full-width photo gallery -> two-column grid below (left: details + amenities + map, right: true cost + CribAI CTA + similar).

Fetch user session server-side with `createSecretClient()` to check saved state.

### Task 2: Saved listings page

**Files:** `apps/web/app/(campus)/[campusSlug]/saved/page.tsx`

Create new server component route:
- Fetch saved listings with join: `saved_listings` -> `listings` via `listing_id`
- Use `createSecretClient()` and get user from session
- If not authenticated, redirect to `/login?returnTo=/${campusSlug}/saved`
- Responsive grid using `ListingCard` (all with `isSaved={true}`)
- Sorted by `saved_listings.created_at DESC` (most recent first)
- Empty state: "No saved listings yet" message + "Find your next place with CribAI" subtitle + CTA button linking to `/${campusSlug}/cribai`
- Page title: "Saved Listings" with count
