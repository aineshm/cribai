## Integration Issues

### HIGH: ChatProvider campusSlug empty in root layout

**Affected:** EXPL-04, DETAIL-05
**Files:** `apps/web/app/layout.tsx:33`, `apps/web/components/chat/ChatProvider.tsx:32`

Root layout `<ChatProvider>` has no `campusSlug` prop → defaults to `''` → `/api/ai/cribai` queries `campus_configs` with `.eq('slug', '')` → 404 "Campus not found". The campus layout correctly passes slug, but Explore page and Listing Detail use root layout.

### MEDIUM: ProfileSetup data not persisted

**Affected:** AUTH-05
**File:** `apps/web/components/auth/AuthForm.tsx:129-137`

`handleProfileComplete` ignores `_profile` argument. Profile step collects firstName, university, graduationYear but never writes to Supabase. Profile page falls back to email-derived defaults and hardcoded university.

### LOW: DETAIL-03 AI summary sub-requirement missing

**Affected:** DETAIL-03
**Files:** `apps/web/lib/mock-listing-detail.ts`, `apps/web/components/listing/ListingContent.tsx`

Landlord info card and amenities grid are present. AI-generated lease summary section is absent — `DetailedListing` type has no `aiSummary` field and `ListingContent` renders no AI summary component.
