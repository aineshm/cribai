       - RLS: SELECT via join through missions (same pattern as logs). UPDATE for user_decision/decided_at only via join. No INSERT policy (service role only).
       - Trigger: `set_draft_not_current()` BEFORE INSERT sets `is_current = false` on all existing drafts for that mission_id (SECURITY DEFINER)
       - Index: `idx_mission_drafts_mission_current(mission_id) WHERE is_current = true`

    5. `mission_steerings` table with: id (UUID PK), mission_id (FK missions CASCADE), raw_input (TEXT NOT NULL), parsed_intent (JSONB nullable), applied_at (TIMESTAMPTZ nullable), created_at

       - Index: `idx_mission_steerings_mission(mission_id, created_at ASC)`

    6. Realtime publications: `ALTER PUBLICATION supabase_realtime ADD TABLE missions, mission_logs, mission_drafts;` (NOT mission_steerings per research)

    8. `update_missions_updated_at()` trigger function + trigger on missions table (same pattern as migration 010)
