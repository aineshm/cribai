## Goal

Add a `get_saved_listings` tool to CribAI so users can reference their saves in conversation, and add a badge on the "Saved" nav link showing count of price-changed saves.

## Tasks

### Task 1: CribAI get_saved_listings tool (schema + handler + executor)

**Files:** `packages/ai/src/tools/schemas.ts`, `packages/ai/src/tools/handlers/get-saved-listings.ts`, `packages/ai/src/tools/executor.ts`

In `schemas.ts`, add `getSavedListings` FunctionDeclaration after `getLandlordInfo`:
- name: `get_saved_listings`
- description: "Get the user's saved/favorited listings. Use when the user asks about their saved listings, favorites, or references 'my saved', 'my favorites'."
- parameters: `sort` (enum: saved_date, price_asc, price_desc, fairness), `limit` (integer, default 10, max 20)
- Add to `CRIBAI_TOOLS` array

Create handler `get-saved-listings.ts`:
- If no `userId` in context, return sign-in prompt
- Query `saved_listings` with `listings!inner(...)` join for full listing data
- Apply sort and limit
- Return `modelContext` with listing summaries JSON and `clientBlock` with recommendations block
- Handle empty results and errors gracefully

Register in `executor.ts`: import and add to HANDLERS map as `get_saved_listings: getSavedListings`.

### Task 2: Nav badge for price-changed saves

**Files:** `apps/web/components/auth-nav.tsx`, `apps/web/components/mobile-nav.tsx`, `apps/web/app/(campus)/[campusSlug]/layout.tsx`

Per CONTEXT.md: "Navigation badge on 'Saved' shows price-changed count, not total saved count."

In campus `layout.tsx`, query:
```sql
SELECT COUNT(DISTINCT n.listing_id)
FROM notifications n
INNER JOIN saved_listings sl ON n.listing_id = sl.listing_id AND n.user_id = sl.user_id
WHERE n.user_id = ? AND n.type = 'price_change' AND n.is_read = false
```

Pass `priceChangedSavesCount` to AuthNav and MobileNav.

In `auth-nav.tsx`: render red badge on "Saved" link when count > 0.
In `mobile-nav.tsx`: render inline badge next to "Saved" text when count > 0.

### Task 3: Integration tests

**Files:** `packages/ai/src/tools/__tests__/get-saved-listings.test.ts`

Tests with mocked Supabase:
1. Unauthenticated user -> sign-in prompt
2. No saved listings -> helpful message
3. With saved listings -> formatted model context + recommendations block
4. Sort parameter passed correctly
5. Limit capped at 20
6. Supabase error -> graceful error message

Run: `cd packages/ai && pnpm vitest run`
