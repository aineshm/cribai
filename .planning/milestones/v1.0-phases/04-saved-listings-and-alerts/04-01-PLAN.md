## Goal

Create the database foundation (saved_listings + notifications tables with RLS), Zod types, and the HeartButton component with optimistic UI. Integrate the heart overlay into ListingCard and the listings page.

## Tasks

### Task 1: Migration `007_saved_listings_notifications.sql`

**Files:** `supabase/migrations/007_saved_listings_notifications.sql`

Create both tables in a single migration:

```sql
-- saved_listings table
CREATE TABLE saved_listings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  listing_id UUID NOT NULL REFERENCES listings(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(user_id, listing_id)
);

ALTER TABLE saved_listings ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users manage own saves" ON saved_listings
  FOR ALL USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);

CREATE INDEX idx_saved_listings_user ON saved_listings(user_id);
CREATE INDEX idx_saved_listings_user_listing ON saved_listings(user_id, listing_id);

-- notifications table
CREATE TABLE notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  type TEXT NOT NULL CHECK (type IN ('price_change', 'listing_inactive')),
  listing_id UUID REFERENCES listings(id) ON DELETE SET NULL,
  payload JSONB NOT NULL DEFAULT '{}',
  is_read BOOLEAN NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

ALTER TABLE notifications ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users see own notifications" ON notifications
  FOR ALL USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);

CREATE INDEX idx_notifications_user_unread ON notifications(user_id) WHERE NOT is_read;
CREATE INDEX idx_notifications_user_created ON notifications(user_id, created_at DESC);

-- Enable Realtime for notifications (bell icon live updates)
ALTER PUBLICATION supabase_realtime ADD TABLE notifications;
```

### Task 2: Zod schemas for SavedListing and Notification types

**Files:** `packages/types/src/saved-listing.ts`, `packages/types/src/notification.ts`, `packages/types/src/index.ts`

Create `saved-listing.ts`:
```typescript
import { z } from 'zod';

export const savedListingSchema = z.object({
  id: z.string().uuid(),
  user_id: z.string().uuid(),
  listing_id: z.string().uuid(),
  created_at: z.string().datetime(),
});

export type SavedListing = z.infer<typeof savedListingSchema>;
```

Create `notification.ts`:
```typescript
import { z } from 'zod';

export const priceChangePayloadSchema = z.object({
  old_price: z.number(),
  new_price: z.number(),
  listing_address: z.string(),
});

export const notificationSchema = z.object({
  id: z.string().uuid(),
  user_id: z.string().uuid(),
  type: z.enum(['price_change', 'listing_inactive']),
  listing_id: z.string().uuid().nullable(),
  payload: z.record(z.unknown()),
  is_read: z.boolean(),
  created_at: z.string().datetime(),
});

export type Notification = z.infer<typeof notificationSchema>;
export type PriceChangePayload = z.infer<typeof priceChangePayloadSchema>;
```

Update `index.ts` to add exports for both new modules.

### Task 3: HeartButton component with optimistic UI

**Files:** `apps/web/components/heart-button.tsx`

Create a client component with:
- Props: `listingId: string`, `initialSaved: boolean`, `campusSlug: string`, optional `size?: 'sm' | 'md'`
- Uses `createClient` from `@campusnest/supabase/client` to toggle save
- Optimistic state: flip heart immediately, revert on error
- CSS keyframe animation: `scale(1) -> scale(1.3) -> scale(1)` on save
- Heart SVG: outline when unsaved, filled red when saved
- Semi-transparent dark background circle for visibility on photos (Airbnb-style)
- On click when unauthenticated: redirect to `/login?returnTo=/{campusSlug}/listings`
- Sonner toast: "Saved to favorites" / "Removed from favorites"
- `onClick` must call `e.preventDefault()` and `e.stopPropagation()` to prevent navigating parent Link
- Supabase INSERT on save, DELETE on unsave matching `user_id` + `listing_id`
