# CampusNest v1.1 — UI/UX Upgrade Release Notes

## Summary
Complete frontend redesign with new design system, marketing landing page, explore/detail pages, post sublease wizard, profile page, and AI concierge UI. Built by 6 parallel agents with zero merge conflicts.

## New Routes
| Route | Page | Phase |
|-------|------|-------|
| `/` | Marketing landing page | P11 |
| `/login` | Split-layout auth with multi-step form | P11 |
| `/explore` | Listing grid + map split view | P12 |
| `/listing/[id]` | Listing detail with photo gallery | P13 |
| `/post` | 6-step sublease posting wizard | P14 |
| `/profile` | Profile + saved listings + settings | P14 |

## Tech Changes
- **Added deps**: framer-motion, lucide-react, shadcn/ui (tw-animate-css, class-variance-authority, clsx, tailwind-merge, @radix-ui/*)
- **Fonts**: Space Grotesk (display) + DM Sans (body) replacing DM Serif Display + Inter
- **Design tokens**: CampusNest brand colors mapped to shadcn CSS variables
- **59 new files** across 9 component directories
- **All existing routes preserved** — v1.0 campus-scoped routes still functional

## Known Issues
- Inline SVG icons in 16 existing v1.0 components not yet migrated to lucide-react
- Map panels are styled placeholders (real map integration planned for v1.2)
- AI Concierge, chat panel, tour booking are UI-only (no backend wiring)
- Photo upload in post wizard is UI-only (no storage integration)
