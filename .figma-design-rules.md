# CampusNest — Figma Design System Rules

> Used by the Figma MCP integration to translate designs into production code.

## Stack

- **Framework**: Next.js 15 (App Router) + React 19
- **Styling**: Tailwind CSS v4 (config-less, PostCSS-based)
- **Fonts**: DM Serif Display (display/headings), Inter (body)
- **Icons**: Inline SVGs (Heroicons v2 outline paths, not the npm package)
- **Images**: `next/image` with `fill` + `sizes` for responsive images
- **Toasts**: `sonner` library
- **Maps**: `mapbox-gl` / `react-map-gl`

## Design Tokens (CSS Variables)

All tokens are defined in `apps/web/app/globals.css` as `:root` CSS variables.
Reference them in Tailwind via arbitrary values: `text-[var(--primary-600)]`.

### Colors

| `--accent-50`, `--accent-100`, `--accent-500` | Soft Coral | Sparingly used accent |
| `--surface-50` (#fafaf9) | — | Page background |
| `--surface-100` (#f5f5f4) | — | Card backgrounds, alternating rows |
| `--surface-200` (#e7e5e4) | — | Borders, dividers |
| `--surface-300` (#d6d3d1) | — | Subtle borders, placeholder icons |
| `--surface-400` (#a8a29e) | — | Secondary/tertiary text, labels |
| `--surface-500` (#78716c) | — | Body text |
| `--surface-600` (#57534e) | — | Light headings, hover nav |
| `--surface-700` (#44403c) | — | Form labels |

### Typography

| Token | Font | Usage |
|-------|------|-------|
| `--font-display` | DM Serif Display 400 | Headings, brand text, card titles |
| `--font-body` | Inter (all weights) | Body, labels, buttons, inputs |

Apply display font: `font-[family-name:var(--font-display)]`
Body font is set on `<body>` — no class needed.

### Shadows

| Token | Usage |
|-------|-------|
| `--shadow-card` | Cards, panels at rest |
| `--shadow-card-hover` | Cards on hover, popovers, modals |

## Component Patterns

### Layout
- **Max-width container**: `max-w-6xl mx-auto px-6`
- **Page background**: `bg-[var(--surface-50)]`
- **Sticky nav**: `sticky top-0 z-50 bg-white/80 backdrop-blur-sm border-b border-[var(--surface-200)]`

### Cards
```
rounded-xl bg-white overflow-hidden shadow-[var(--shadow-card)]
hover:shadow-[var(--shadow-card-hover)] hover:-translate-y-0.5
transition-all duration-200
```

### Buttons
- **Primary**: `rounded-lg bg-[var(--primary-600)] text-white hover:bg-[var(--primary-700)] px-4 py-2 text-sm font-medium transition-colors`
- **Secondary/Ghost**: `rounded-lg border border-[var(--surface-200)] text-[var(--surface-600)] hover:bg-[var(--surface-50)] px-3 py-2 text-sm transition-colors`
- **Chip/Pill**: `rounded-full border border-[var(--surface-200)] bg-white px-3.5 py-2 text-xs text-[var(--surface-600)] hover:border-[var(--primary-400)] hover:text-[var(--primary-700)] hover:bg-[var(--primary-50)] transition-colors`

### Form Inputs
```
rounded-xl border border-[var(--surface-200)] bg-white px-3 py-2 text-sm
text-[var(--surface-700)]
focus:border-[var(--primary-500)] focus:outline-none focus:ring-1 focus:ring-[var(--primary-500)]
transition-colors
```
Active/selected state: `border-[var(--primary-400)] bg-[var(--primary-50)]`

### Chat Bubbles
- **User**: `rounded-2xl rounded-br-sm bg-[var(--primary-600)] text-white`
- **Assistant**: `rounded-2xl rounded-bl-sm bg-[var(--surface-100)] text-[var(--surface-800)]`

### Badges
- **Fairness score**: `rounded-full px-2.5 py-1 text-xs font-semibold` + dynamic color from `getScoreColorVariants()`
- **Freshness**: Pill badge showing verification recency

## Animations

| Class | Effect | Duration |
|-------|--------|----------|
| `animate-fade-in` | Fade in + translateY(8px) | 300ms ease-out |
| `animate-slide-up` | Fade in + translateY(16px) | 400ms ease-out |
| `animate-heart-pop` | Scale bounce 1→1.3→1 | 300ms ease-in-out |
| `stagger-item` | Fade-in with `--stagger-index * 50ms` delay | 300ms each |
| `pulse-dot` | Typing indicator dots | 1.4s infinite |

## Responsive Breakpoints

Standard Tailwind breakpoints:
- `sm:` (640px) — 2-column grids
- `md:` (768px) — Desktop nav, layout shifts
- `lg:` (1024px) — 3-column listing grid

Mobile-first design: base styles target mobile, breakpoints add desktop behavior.

## Icon Conventions

All icons are inline `<svg>` elements in JSX:
- `fill="none"` + `stroke="currentColor"` (outline style)
- `strokeWidth={1.5}` for content icons, `strokeWidth={2}` for UI chrome
- Size via Tailwind: `h-4 w-4` (small), `h-5 w-5` (default), `h-6 w-6` (feature), `h-8 w-8` (hero)
- Color inherited from parent via `currentColor`

## Image Handling

Use `next/image` with:
- `fill` prop + parent `relative` container for responsive images
- `sizes` attribute matching grid: `(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 33vw`
- `priority` only on above-the-fold hero images
- Fallback: teal-tinted placeholder div with camera icon

## File Organization

- Components: `apps/web/components/*.tsx` (flat, one component per file)
- Chat components: `apps/web/components/chat/*.tsx`
- Lib/utils: `apps/web/lib/*.ts`
- Pages: `apps/web/app/` with Next.js App Router conventions
- Shared types: `packages/types/`
